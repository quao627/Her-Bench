# Minecraft 早期关键合成配方（Java 版）

> 来源：https://minecraft.wiki/w/Crafting 、https://minecraft.wiki/w/Tutorial:Beginner's_guide

说明：背包自带 2×2 合成格，工作台提供 3×3 合成格。下面用文字精确描述摆放位置。

## 基础材料

- **木板**：1 根原木放入任意格 = 4 块木板（2×2 即可）。原木靠空手或斧头砍树获得。
- **木棍**：2 块木板竖着上下叠放 = 4 根木棍（2×2 即可）。
- **工作台**：4 块木板摆满 2×2 格 = 1 个工作台。放置后右键使用。

## 工具（都需要 3×3 工作台）

工具分材质等级：木 → 石 → 铁（早期到铁为止），越高级越快、越耐用。石制材料用圆石（木镐挖石头掉落），铁制材料用铁锭（石镐挖铁矿，熔炉烧炼获得）。

- **镐**：顶行横排 3 个材料（木板/圆石/铁锭），中间列的中格和下格各放 1 根木棍。共 3 材料 + 2 木棍。
  - 木镐能挖：石头、煤矿。
  - 石镐能挖：以上 + 铁矿。
  - 铁镐能挖：以上 + 金矿、红石、钻石。
  - 注意：用低级镐挖高级矿（比如木镐挖铁矿）不会掉落任何东西，白挖。
- **斧**：2 个材料竖放在左列上格和中格，1 个材料放顶行中格，2 根木棍放中间列的中格和下格（整体呈 "「" 形）。共 3 材料 + 2 木棍。砍树更快，也能当武器。
- **剑**：中间列从上到下依次是：材料、材料、木棍。共 2 材料 + 1 木棍。木剑伤害低，尽快换石剑。

## 生存设施

- **熔炉** = 8 块圆石围一圈：3×3 格摆满圆石，只留正中间一格空着。用途：烧炼矿石、烤熟食物、烧原木得木炭。燃料可用煤炭、木炭、木板等。
- **床** = 3 块同色羊毛 + 3 块木板：顶行（或中行）横排 3 块羊毛，其正下方一行横排 3 块木板。羊毛靠剪刀剪羊或直接杀羊获得，3 块必须同色。天黑或雷雨时右键睡觉可跳过夜晚，并把重生点设在床边。
- **火把** = 1 根木棍 + 1 块煤炭或木炭：煤/木炭放上格，木棍放正下方格（2×2 即可），一次出 4 支。煤炭挖煤矿获得；木炭是把原木放进熔炉烧出来的，早期没找到煤矿时的替代品。
- **门** = 6 块木板：在 3×3 格中用两列各竖放 3 块木板（占满左右相邻两列共 6 格），一次出 3 扇木门。装在住所入口，僵尸在普通难度砸不烂木门（困难难度可以砸破，注意）。

## 早期合成路线建议

砍 4~6 根原木 → 全变木板 → 工作台 + 木棍 + 木镐 → 挖 14+ 圆石 → 石镐、石斧、石剑、熔炉 → 烧木炭做火把 → 找羊做床 → 有铁矿后烧铁锭，换铁镐铁剑。
