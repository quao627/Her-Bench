## 一、"我是不是把游戏玩坏了？"——最高频的误判

这游戏里"看起来像 bug 的东西"大多是内容。Steam 上一个帖子标题就是这个问题：**"Without spoilers, please ... am I supposed to get stuck and restart?"** 楼主说自己遇到了无限循环，还被困在一条走廊里、旁白突然不说话了，问是不是漏了什么操作。回复很干脆：

> "There are some situations in which restarting the game is the only way out."
> — 用户 Doppy37

**对陪玩的用法**：她怀疑卡住 / 崩溃 / 出 bug 的时候，先看客观证据——旁白还在说话吗？字幕还在走吗？屏幕上有没有报错？如果有旁白和字幕、没有报错，那基本可以断定是演出，不是故障。**长时间黑屏、突然切成第三人称、突然没法移动，都是这游戏的常规手段。**

反例也存在：确实有真正走不出去的段落（Playtest Ending 尾巴那片编号 500 多的废弃办公室，社区帖里有人形容成 "a beta version of the office"，走进去就永久困住，只能自己重开）。所以"重开一下"在这游戏里既不是投降也不是万能药，就是正常操作之一。

## 二、"这也算结局？"——短结局引发的困惑

Fandom 自己都给 Broom Closet Ending 和 Whiteboard Ending 打了标注 "technically not an ending"，因为它们不触发重开、玩家可以直接继续。社区里因此长期存在"到底哪些算结局"的争论，各家攻略的分类也不一样：

- Fandom 按门分类（左门 / 右门 / 两扇门之前 / 进度线），算 UD 45 个。
- gamepressure 说 27 个。
- Steam 指南作者 Arburo 分成 "vanilla 14 + new 20 + extra 2"，把 Broom Closet 和 Whiteboard 单独归为 "extra"。

**同一个结局在社区里往往有好几个名字**，这点在跟玩家对话时值得注意（也提醒 agent 别把某个名字当成"官方唯一叫法"）：

| Freedom Ending | True Ending / Correct Ending / Life Ending |

## 三、"You can't jump" 成就：玩家自己也说不清怎么触发的

原版讨论区有整整几个帖子在问这个成就为什么不弹（"You can't Jump Problem"、"Bug with 'You can't jump'"、"'You Can't Jump' HELP"）。玩家给出的经验互相矛盾：

- 有人说在平地上狂按空格没用，得**在"有东西可以跳上去"的场合**尝试才行；
- 有人说自己是"在 Freedom Ending 里想跳过那个巨大的黑色物体时"拿到的；
- 有人说是"在满是按钮的 mind control 房间里跳"拿到的；
- 也有人排查到最后发现是**跳跃键位没绑到空格**。

Fandom 的 Achievements 页给的官方口径最简单：**在游戏里反复按跳跃键就行**；Ultra Deluxe 多一条限制——**必须在 jump circle 之外，或者 36 次跳跃已经用完**，否则不会弹（因为那时候你确实能跳）。

**对陪玩的用法**：这个成就本身就是在拿"这游戏没有跳跃功能"开玩笑，成就描述原文是 "No seriously, we disabled it."（不是开玩笑，我们真把它禁了）。玩家按不动**不是操作失败也不是游戏出错**。至于"到底怎么才能稳定触发"，社区没有共识，别给她一个精确的说法。

## 四、"Unachievable" 成就：作者会主动改条件

原版有个成就叫 **Unachievable**，描述写着"It is impossible to get this achievement."。社区确实找到过办法（早期是改 `config.cfg` 绑一个特殊按键），但讨论帖里反复提到一件事：

> 作者会在方法被公开之后修改条件。

所以网上流传的具体做法**随时可能失效**，不同年份的帖子给的方法都不一样。这条对 agent 的意义是：**别把某个网上抄来的成就做法当成确定事实说出去。**

## 五、Ultra Deluxe 特有的卡点：新内容门"消失了"

这是 UD 讨论区最集中的一类求助。典型情形：玩家走完 New Content 那条线之后，那扇门就不见了，怎么找都找不回来，以为自己玩到头了。

一个玩了七小时的楼主（Storm909）说自己"锁死在 THE SEQUEL 里了"，普通结局基本都走完、手办也集齐了，就是找不到 "new content" 或 "new new content" 门。回复给出的关键是：

> "You know how when you start the game it asks you questions about the time and gives you sliders to adjust? And it's different each time? Well, once you've done that a few times you will get a new option called 'Epilogue' in the game menu."
> — 用户 Hamakei

也就是说：**要反复完整退出游戏再打开（社区经验是 2–5 次），主菜单才会长出 Epilogue 选项；走完 Epilogue，新内容门才会回来。** 另一位回复者补充说，Epilogue 之后地下室那台原本用不了的 achievement machine 也会变得能用。

同一批帖子里还有人卡在别的地方：门消失后试了一个多小时、按各种顺序重走都没用。这说明**这个机制在游戏内几乎没有提示**，是设计上有意为之的"你得先离开游戏才能继续"。

## 六、Infinite Hole：一个真·提示错误

UD 的 Infinite Hole 段落里，屏幕提示按 **E** 传送出去，但实际生效的是 **G**。讨论帖 "stuck in infinite hole?" 里楼主换了好几个键位、用鼠标试都没用，直到有人告诉他按 G：

> "the game prompts me to press E and nowhere is it stated that i had to press G to teleport back up."

后续有人发现这跟 "simplify controls" 这个设置有关，关掉之后提示就正确了。也有人认为这是故意的。**结论：这是本作里少数"提示确实和实际不符"的地方，但它也不影响进程——待够久了这段自己会往下走。**

## 七、Confusion Ending 的时刻表对不上

原版讨论区那个置顶的 "Secrets FAQ! Spoilers!"（作者 rollyscrolly）记了一条有意思的观察：Confusion Ending 里那块电子时刻表**列出了 8 次重开**，但实际上：

> 只走到第 4 次左右，第 5 次重开之后游戏就恢复正常了，时刻表上后面写的那些内容从来没人找到过对应的段落。

Fandom 的 Confusion Ending 页也是这么写的（"despite what is stated on the schedule board, the Confusion Ending is over and gameplay returns to normal"）。**所以那块表上写的"未来事件"是设计上的玩笑，不是没做完的内容，也不是需要玩家去解锁的东西。**

## 八、这些讨论对陪玩的三条实用结论

1. **先分清"故障"和"演出"。** 判断依据只用屏幕上有的东西：旁白还在说话吗、字幕还在走吗、有没有报错。有旁白有字幕没报错，就不要往显卡、画质设置、驱动、录屏软件那边带。
2. **她怀疑"这算结局吗"时，答"这游戏的结局长短差得极大"是安全的**，答"你刚才那个是 XX Ending"就不安全。社区自己都对"哪些算结局"没共识，更不用说结局名字本身就是剧透。
3. **别转述网上抄来的精确触发条件。** 成就怎么弹、门什么时候会变、要重开几次——这些社区说法互相打架，而且部分随版本变动。视频里没交代的，就说"没交代"。
